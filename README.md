CharClass — a char-code state-machine CSV reader. It returns exactly the answer csv-reader 1.0.0 returns for every input — same columns, rows and broken-row errors — and runs faster: run(input) in solve.js is a drop-in replacement, driven by main.ts, which reads /input/cases.json and writes /output/answers.json.

## Run it

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```
